# Profile Photo Setup

Please add your profile photo to the following location:

**Path:** `public/assets/images/profile.jpg`

You can use either:
- `profile.jpg`
- `profile.png`

The photo will be displayed as a circular image in the loading animation.

**Recommended:**
- Square aspect ratio (1:1)
- Minimum size: 200x200 pixels
- Clear headshot photo
